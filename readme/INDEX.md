## Map

- `../README.md`: public project overview, release channel, v1.19.0 highlights,
  install links, and quick feature summary.
- `CN.md`: Chinese public project overview, release channel, v1.19.0 highlights,
  install links, and quick feature summary.
- `FEATURES.md` / `FEATURES_CN.md`: fuller feature tour for Home, OS, MCP, GitHub
  tracking/subscription projects/discovery/Star import, Blue Archive, Student Guide, settings, and
  i18n.
- `BUILD.md` / `BUILD_CN.md`: local build, versioning, CI APK, signing, nightly.link, live GitHub
  strategy/subscription tests, and screenshot-baseline workflow.
- `../docs/build/github-actions.md`: CI triggers, manual inputs, package/signing choices,
  artifact checksums, reports, cancellation, and workflow maintenance.
- `../feature-webdav/README.md`: synchronization and restore rules, Nutstore setup, protocol
  ownership, compatibility, failure handling, and verification.
- `../docs/README.md`: engineering documentation by ownership: build, performance, planning, and QA.
- `../docs/planning/android-appwidget-oem-study.md`: official Android and OEM widget research,
  verified extensions, unresolved vendor contracts, and implementation/acceptance planning.
- `../docs/planning/github-project-widget.md`: widget entry, responsive layouts, privacy, cached
  data, lifecycle ownership, and OEM addition limits.
- `../build-logic/README.md`: convention plugins, version/profile helpers, and included-build checks.
- `RELEASE_V1.19.0.md`: bilingual update notes for BGM playback, launcher icons, imports, unfinished
  edits, reminders, window resizing, and upgrading.
- `RELEASE_V1.18.0.md`: retained bilingual notes for the published v1.18.0, including Sheet/performance
  and notification fixes and upgrade guidance.
- `RELEASE_V1.17.0.md`: retained bilingual v1.17.0 notes, installation guidance, and compatibility notes.
- `RELEASE_V1.16.0.md`: retained bilingual notes for the local v1.16.0 development milestone.
- `RELEASE_V1.15.0.md`: archived bilingual GitHub Release notes for v1.15.0.
- `RELEASE_V1.14.0.md`: archived bilingual GitHub Release notes for v1.14.0.
- `TODO.md` / `TODO_CN.md`: Android 17, OEM beta, and large-screen roadmap items.
- `../CODE_OF_CONDUCT.md`, `../CONTRIBUTING.md`, `../SECURITY.md`: GitHub Community Standards files
  for contributors and security reporters.
